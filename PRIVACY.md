# Privacy policy

Effective date: September 3, 2026

MStack is a collection of local skills and does not operate a hosted service. The MStack repository does not collect, retain, sell, or transmit user data.

Some workflows can invoke tools or model providers that the user has installed and configured, including Codex, Claude Code, GitHub, and project-management connectors. Those tools can receive prompts, source code, command output, or other context needed for the requested workflow. Their own privacy policies, account settings, and access controls govern that processing.

MStack does not include credentials. Users are responsible for deciding which tools and repositories a workflow may access. Capability failures must be reported rather than bypassed with undeclared services.

Report privacy concerns through [GitHub Issues](https://github.com/muneebshahid/mstack/issues).
