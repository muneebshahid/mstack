# Verification

## Prove the real result

Gather fresh evidence from the artifact or behavior being claimed. Inspect resulting files and diffs, exercise the relevant input-to-output path, and verify delegated output directly.

Match evidence to the claim. Lint and formatting check source conformance; types check static consistency; tests cover the behavior they exercise; builds establish compilation or packaging. Run required project checks and exercise the closest surface to the changed behavior. For browser changes, check affected journeys and relevant states, reporting failures and material skips with reasons.

Automate evidence gathering when repeatability, risk, or regression value repays maintenance. Otherwise direct observation can suffice. Retain evidence artifacts only when their value justifies the cost and they are authorized, and report material unexercised surfaces.
