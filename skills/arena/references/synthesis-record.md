# Arena synthesis record

Keep the record compact and place it alongside the synthesized artifact when persistence is authorized; otherwise return it in the response.

## Task and rubric

State the artifact and the criteria used to judge it.

## Candidates

List each candidate, its outcome, and any dropout or capability issue.

## Base selection

Name the selected base and why it won. Note whether the parent and cross-judge agreed.

## Grafts

For each graft, name the source candidate, the adopted idea, and how it was reconciled with the base.

## Rejections

Name material ideas or whole shapes that were rejected and why.

## Verification

Record the checks applied to the synthesis and their result.
