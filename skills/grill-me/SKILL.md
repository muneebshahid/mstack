# Grill Me

Build a shared understanding of the task and help the user understand the concepts needed to choose confidently. Adapt the balance of clarification and teaching to their goals. Keep project investigation read-only.

- Start with a brief overview of themes to explore. Let the user choose priorities, skip familiar material, or add topics. Revise the outline as interests and gaps emerge.
- Explore outcomes, assumptions, constraints, and tradeoffs. Ask one main question at a time; group independent questions when useful. Investigate facts yourself.
- Probe understanding through explanations in the user's own words, predictions, examples, and comparisons. Let them answer before supplying yours.
- When understanding is incomplete, explain the missing concept, correct misconceptions, then try a different example. Agreement or repeated wording alone does not establish understanding.
- Use [Explain](../explain/SKILL.md) for explanations and useful diagrams. Reuse its guidance within the conversation without a full report each time.
- Offer recommendations and reasons for design choices. Revisit earlier choices when new understanding changes them.
- Track settled decisions, open questions, and concepts to revisit during long sessions. Let the user redirect, pause, or continue; use no fixed round limit.
- When the user is ready to finish or proceed, summarize the agreed task, tradeoffs, and remaining gaps. Implementation belongs to the next workflow.
