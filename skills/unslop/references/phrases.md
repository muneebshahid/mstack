# Phrases

Use these as editing cues, not a word blacklist. Keep language that carries a precise meaning or fits the requested voice.

## Openers and announcements

Usually delete the introduction and state the point:

| Pattern | Edit |
| --- | --- |
| "Here's the thing", "Here's the kicker", "Here's what most people miss" | Start with the observation. |
| "Let me be clear", "The truth is", "I'm going to be honest" | State the claim without announcing sincerity. |
| "It's worth noting", "It bears mentioning", "When it comes to" | Remove the filler. |
| "Let's unpack this", "Let's dive in", "Let me walk you through" | Begin the explanation. |
| "In this section, we'll", "As we'll see" | Remove previews that add no navigation value. |
| "In conclusion", "To sum up", "And so we return" | End with the useful conclusion itself. |

## Plain replacements

Replace inflated wording when the simpler term preserves meaning. Technical uses of words such as "framework", "robust", and "ecosystem" may be exact.

| Wording | Possible replacement |
| --- | --- |
| utilize, leverage as a verb, harness | use |
| navigate challenges | address the problems |
| unpack, delve into, deep dive | explain, examine |
| streamline | simplify, or name the steps removed |
| moving forward | next |
| circle back | revisit |
| landscape, tapestry | field, system, mix, or the actual subject |
| paradigm, synergy | approach, cooperation, or the specific mechanism |
| serves as, stands as, represents | is, when that is the intended meaning |
| game-changer, transformative, revolutionary | the actual change and its effect |

## Empty emphasis

Cut "really", "genuinely", "deeply", "remarkably", "fundamentally", and "quietly" when they add only emphasis. Keep modifiers that describe actual behavior, degree, timing, or uncertainty.

Remove "Full stop", "Let that sink in", "Make no mistake", and "I promise" when they merely demand agreement.

## Claims that need substance

| Pattern | Edit |
| --- | --- |
| "The implications are significant", "The reasons are structural" | Name the consequence or cause. |
| "Experts argue", "Industry reports suggest" | Identify the available source and represent its scope accurately. |
| "highlighting its importance", "reflecting broader trends" | State the supported connection or delete the clause. |
| "will define the next era", "changes everything" | Match the claim to the evidence. |
| "the supervision paradox", "the acceleration trap" | Describe the problem; define a new term only if it helps. |
| "And yes, since we're being honest" | Keep the author's actual experience, without performed intimacy. |

If the missing detail is unavailable, preserve the uncertainty or identify the gap. Do not fill it with plausible specifics.
