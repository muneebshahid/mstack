# Unslop

Make prose direct, specific, and natural. Use judgment: a listed pattern can work in context; repeated patterns often need editing.

Preserve facts, uncertainty, citations, technical terms, and the author's position. Respect the requested audience, format, and voice. Leave exact quotations, code, structured data, and legal text unchanged.

## Edit

- State the point early. Cut preambles, filler, exaggerated significance, and repeated conclusions.
- Prefer familiar words and concrete descriptions. Keep one name for each thing; remove invented labels that obscure the meaning.
- Replace vague claims with evidence already available. Do not invent numbers, examples, sources, personal experiences, or beliefs to make prose sound specific or human.
- Name the actor when it helps. Keep passive voice when the actor is unknown or irrelevant.
- Connect related ideas and vary sentence length. Cut forced contrasts, rhetorical reveals, repeated openings, and fragments used for drama.
- Preserve useful qualifications. Remove empty emphasis without changing confidence, scope, or conditions.
- Use the formatting the content needs. Trim decorative emphasis, unnecessary headings, and lists that repeat the prose.

Keep the author's voice and supported judgments. Do not add personality for its own sake or make every sentence sound alike.

Use [Phrases](references/phrases.md) for word-level edits, [Structures](references/structures.md) for repeated sentence and document patterns, and [Examples](references/examples.md) for worked rewrites. Read only what helps the current edit.

## Return

When drafting, apply this guidance silently. When revising, return the edited text first; explain changes only when requested or useful.

Before returning it, check that the rewrite preserves meaning and adds no unsupported claims. Cut any filler introduced by the edit itself.
